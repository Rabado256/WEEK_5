
# Averon Academy — Week 5: Persistent Task Manager

A feature-rich, responsive Task Management web application built with vanilla HTML5, CSS3, and JavaScript, leveraging arrays of objects, modern ES6+ features, and the Browser LocalStorage API for long-term data persistence.

---

## 🚀 Features
1. **Task Creation:** Add new tasks dynamically with input validation.
2. **Persistence:** Automatically saves tasks to browser `localStorage` so data survives page refreshes and browser restarts.
3. **Completion Tracking:** Mark tasks as complete or incomplete with live visual strikethroughs.
4. **Filtering System:** Seamlessly filter tasks by **All**, **Active**, and **Completed** views.
5. **Dynamic Counters & Batch Actions:** Real-time counter of remaining active tasks and a quick action button to clear all completed tasks.
6. **Responsive Design:** Optimized layout scaling smoothly across mobile devices and desktop screens.

---

## 💻 How to Run Locally
1. Clone or download this repository.
2. Open the workspace folder in **Visual Studio Code**.
3. Navigate to the `week-05/` directory.
4. Right-click `index.html` and select **"Open with Live Server"**.
